# For My Sweetheart 💖

A special romantic surprise website built with React, Vite, Lucide Icons, and Canvas Confetti.

## ✨ Features
- 💌 **Romantic Love Letter**: Heartfelt messages and full-screen wax-sealed letter modal.
- 📸 **Polaroid Photo Album**: 8 memory photos with realistic polaroid tilts, dates, quotes, like counts, slideshow mode with autoplay, and full lightbox zoom.
- ✉️ **"Open When..." Capsule**: 4 interactive envelopes for comfort, smiles, and sweet moments.
- 🎟️ **Love Voucher Book**: Redeemable romantic coupons with "Accepted With Love" celebration stamps.
- 🎵 **Romantic Music Box**: Web Audio API melody player with animated visualizer bars.
- 🌸 **Interactive Floating Hearts**: Ambient floating symbols and click-burst hearts wherever you click.

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hanpichpharong/snp-jit.git
   cd snp-jit
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run development server:**
   ```bash
   npm run dev
   # or on Windows PowerShell:
   npm.cmd run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
